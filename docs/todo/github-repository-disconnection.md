# 대량 저장소 연결 해제 개선

상태: 후속 규모 검토. 전체 전환 원자성은 제공하지 않음.
관련: [PLAN-0017 Task 수명주기](../plans/PLAN-0017-github-app-issue-task-integration.md#task-수명주기와-데이터-소유권)

## 현재 범위와 한계

현재 PLAN은 disconnecting 전환, 동기화 차단, batch 전환, 진행률과 부분 완료·재시도를 구현한다.
모든 Task를 한 transaction에서 일반 Task로 바꾸는 원자적 해제는 채택하지 않는다.
전환 완료 사본과 미전환 보호 항목은 구분하며 권한 상실 후 내용 비노출 정리를 지원한다.
사용자가 잠시 갱신만 멈추려면 현재 PLAN의 일시 중지/재개를 사용한다. 이는 Task 전환이나 연결 해제가 아니며 권한 확인은 유지된다.
기존 일반 Task에 Issue를 연결하는 기능은 없고, 정리 대상 GitHub Task는 Issue에서 새로 가져온 항목이다.

## 후속 작업

- [ ] 대규모 연결의 처리 시간·잠금 대기·실패 재개 비용을 측정한다.
- [ ] 필요할 때 batch 크기와 작업 공정성을 개선한다.
- [ ] 사용자가 요청하면 취소·되돌리기 가능성을 별도 검토한다. 이미 수정한 일반 Task를 자동 재연결하지 않는다.
- [ ] 전체 원자성 요구가 실제로 생긴 경우에만 데이터 모델 변경 비용과 필요성을 다시 평가한다.

## 검증 기준

중간 종료·부분 완료·권한 철회·동시 Task 편집 이후 중복 변환이나 원본 복원이 없어야 한다.
전체 원자성을 미완료 버그로 간주하지 않는다. 기본 batch 해제와 정리 검증은 현재 PLAN 필수다.
