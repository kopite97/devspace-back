# 긴 GitHub Issue 원문 보존

상태: 이번 PLAN 범위 밖 기능 후보.
관련: [PLAN-0017 Issue 조회와 가져오기](../plans/PLAN-0017-github-app-issue-task-integration.md#issue-조회와-가져오기)

## 현재 범위

Task 제목 160자·설명 10,000자 제한을 유지한다.
최초 초과 항목은 거부하고, 연결 후 초과 시 마지막 정상 내용을 유지하며 오류를 표시한다.
원문이 정상 길이로 돌아오면 복구한다. 일반 Task 전환도 마지막 정상 로컬 내용을 사용한다.

## 후속 작업

- [ ] 실제 제한 초과 사례와 사용자가 필요한 원문 조회·편집 범위를 확인한다.
- [ ] 외부 원문 별도 저장과 Task 표시용 요약 모델을 비교한다.
- [ ] UTF-16/byte 제한, 최대 원문 크기, Markdown·이미지 처리, 저장/응답 비용을 정의한다.
- [ ] private 접근 철회와 정리 정책을 별도 원문에도 적용한다.
- [ ] 일반 Task 전환·검색·내보내기 시 전체 원문과 요약 중 무엇을 사용하는지 확정한다.
- [ ] API·migration·프론트엔드 표시 계약을 별도 승인된 구현 계획으로 작성한다.

## 검증 기준

무손실을 제공하는 범위와 최대 크기를 명시하고, 조용한 잘림·표시와 저장 간 불일치를 방지한다.
일반 Task 제한을 일괄 확대하는 방식으로 시작하지 않는다.
이번 작업은 개발일지·문서 연동을 포함하지 않는다.
