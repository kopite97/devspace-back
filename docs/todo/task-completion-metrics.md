# 취소를 구분하는 Task 완료 성과 통계

상태: 이번 PLAN 범위 밖 기능 후보.
관련: [PLAN-0017 상태 라벨 매핑](../plans/PLAN-0017-github-app-issue-task-integration.md#상태-라벨-매핑)

## 현재 범위

기존 통계는 접근 가능한 Task의 todo/doing/done 개수다. 완료 성과를 뜻하지 않는다.
not_planned로 닫힌 Issue가 기존 done을 유지하면 done 개수에도 포함하고 미진행 종료를 따로 표시한다.

## 후속 작업

- [ ] 완료 성과의 단위·기간·분모와 취소/중복/미진행의 분류를 정의한다.
- [ ] 완료 후 재개방·취소, 일반 Task 전환, 삭제·복원에 대한 집계 규칙을 정한다.
- [ ] 현재 상태만으로 충분한지, 상태 변경 이력과 완료 시각을 저장해야 하는지 검토한다.
- [ ] 일반 Task와 GitHub Task의 기준을 맞추고 권한 상실에 따른 지표 변화를 명시한다.
- [ ] 기존 보드 개수와 새 성과 지표를 구분한 API·화면 계약을 작성한다.

## 검증 기준

done → not_planned, 완료 → 재개방 → 재완료에서 중복 실적이 생기지 않아야 한다.
도입 이전 이력을 현재 상태로 추정해 실제 기록처럼 표시하지 않는다.
일반 보드 상태·목록·total의 기존 의미는 유지한다.
